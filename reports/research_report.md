## 摘要

1. **数据**：1,435 只股票，365 万条股票日记录。
   - 与 baostock 独立数据源交叉验证：日收益误差小于 0.1pp 的比例为 **99.95%**。
   - 推断的 ST 标记：精确率 81.5%，召回率 69.8%。
   - 基本面严格按公告日时点对齐（point-in-time）。
2. **因子**：构建 19 个因子，按 |t|≥2、|ICIR|≥0.5、相关性 <0.6 筛选。
   - **滚动选因子**：每个调仓日用同一规则重新筛选，只用该日之前已实现的标签（扩展窗口，至少 24 个月），平均每月选中约 10 个。偏度、EP、价量相关、换手、MAX、特质波动几乎每月都入选。
   - 最强的是**低风险 / 低关注类**因子：价量相关、MAX、偏度、特质波动、换手，样本内 |ICIR| 在 1.5–1.8 之间。
3. **模型**：三种 walk-forward 模型，只用已实现的标签训练，按样本内 ICIR 选出 **Ridge**（1.33，ICIR 加权 1.14，GBDT 1.29）。
   - 去掉"用整段样本内选出的因子"带来的偏差后，ICIR 加权的样本内 ICIR 从 1.44 降到 1.14，这正是 v3 选中它的原因。
   - 三种模型的样本外 RankIC 都在 0.057–0.068，信号没有衰减。
4. **组合**：简化 Barra 风险模型 + cvxpy 优化。优化器每月从**回测中的实际持仓**出发，约束主动权重、行业、市值和换手。回测是持仓市值 + 现金的账户：买不进的资金留作现金，交易成本从现金支付，不借钱。
   - λ 按**风险预算**选：网格中样本内平均事前跟踪误差最接近 4% 的值，结果 λ = 5，平均持仓约 66 只。选择时不看收益。
   - **样本外**：年化 2.52%，基准 1.05%，**超额 +1.45%**，信息比率 **0.25**，跟踪误差 5.2%，成本拖累 0.69%/年。
   - **样本内**：超额 −1.51%，信息比率 −0.35。
5. **稳健性**（第 5.6 节，每一行都是完整重跑）：
   - 跟踪误差目标换成 3% / 5%，样本外 IR 为 0.33 / 0.23；v2 的"样本内 IR 最高"规则（λ = 50）为 0.45。
   - 加风格或行业约束、换样本切分、扰动财报数据，IR 在 0.11 到 0.42 之间；换成 ICIR 加权或 GBDT 模型（各自重新校准 λ）为 0.10 和 −0.25。
   - Bootstrap：样本外 IR 的 95% 区间为 [−0.72, 1.26]，重抽样中主动收益 ≤ 0 的比例约 31%。
   - 容量：按平方根冲击模型，1 亿元时额外冲击约 0.7%/年，5 亿元时基本吃掉全部超额。
6. **基准口径**：这是**自定义流通市值基准增强**，不是官方中证800指数增强。两者每年相差 2–5%。
7. **结论**：信号层面稳定；以 4% 跟踪误差的风险预算做 long-only 增强，历史回测的超额约 +1.4%，**方向为正但统计上不显著**，各种合理方案收敛到 IR 0.1–0.45。由于 2022 年以来的数据在开发中被反复查看，真正的检验要看冻结之后的**前瞻样本**（目前已登记第一期目标仓位，尚无前瞻收益）。

## 1. 数据获取与质量审计

### 1.1 数据源

| 数据 | 来源 | 说明 |
|---|---|---|
| 日线（不复权 OHLCV、流通股本）+ 后复权因子 | 新浪（AkShare） | 收益 = close / preclose − 1，preclose = close(t−1)·f(t−1)/f(t)，自动包含分红送转 |
| 季度业绩报表（EPS、营收、净利润、BVPS、毛利率、同比） | 东方财富（AkShare） | 2014Q1 ~ 2026Q3，共 51 期 |
| 时点成分股、行业（证监会分类）、上市日期、价格指数 | baostock | 月度沪深300 + 中证500 快照 → 时点中证800 |
| 全收益指数 H00906 / H00300 / H00905 | 中证指数公司（AkShare） | 业绩基准（含分红） |

> **工程教训**：最初用 baostock 下载日线时开了 12 个并发，触发了服务器的反滥用机制，IP 被封。之后的下载器做了三件事：所有线程共享一个全局限速（≥0.8 秒/次）；失败后指数退避重试；原子写入，支持断点续传。

### 1.2 时点（point-in-time）处理

- **股票池**：用每月的成分股快照，不用今天的成分股，避免幸存者偏差。
- **财报公告日**：东方财富的「最新公告日期」**不是首次披露日**，常常是次年年报重述比较数据的日期。
  - 第一版直接用了这个字段，审计显示报告的中位滞后高达 466 天。
  - 修正后按 min(最新公告日, 法定截止日) 估计首次披露日：一季报 4/30，半年报 8/31，三季报 10/31，年报次年 4/30。
  - 财报从公告**次日**起才可用。修正后中位滞后为 116 天。
- **TTM**：本期累计值 + 上年年报 − 上年同期累计值。
- **每股指标换算到当天股本**：EP = EPS_TTM × f(公告日) / (close × f(t))。这样送转股不会让 EP 跳变，有单元测试覆盖。
- **迟到的旧报告期数据**：新一期报告公布后才到的旧期数据直接丢弃（不覆盖已有的新数据）。

### 1.3 审计结果（摘录）

| 检查项 | 结果 |
|---|---|
| 重复记录 / 非交易日 / OHLC 不一致 | 0 / 0 / 0 |
| 与 baostock 交叉验证（180 只股票，44 万个股票日） | 收盘价一致率 99.8%；日收益误差 <0.1pp 的比例 99.95%；相关系数 0.9993 |
| ST 推断（60 日内触及 ±5% 涨跌停价 ≥3 次，且没有 >5.5% 的波动） | 精确率 81.5% / 召回率 69.8%，参数在交叉验证集上网格搜索得到 |
| 基本面缺失率（EP/BP/ROE） | 0.1% ~ 0.5% |
| 停牌股票日占比 | 2.0% |
| 流通市值复原的中证800 vs 官方全收益指数 | 相关系数 0.988，年化跟踪误差 3.4% |

**基准口径**：官方指数用**自由流通市值**加权（剔除控股股东持股），并做分级靠档和权重上限，历史成分权重无法免费获取。本项目只有流通市值，大型国企的权重被高估，复原值和官方指数每年相差 2–5%。所以本项目定位为**自定义流通市值基准增强**。

优化器跟踪的正是流通市值权重，所以：
- **主口径基准**：复原的中证800（含分红）；
- **副口径**：同时报告相对官方全收益指数的超额。

两个口径之差来自基准构造，和选股能力无关。

### 1.4 已知局限

- 79 只已退市股票在新浪没有数据，存在残余的幸存者偏差，会轻微高估收益。
- 行业用的是当前的证监会二级分类（约 76 个），不是时点数据。
- 报表数值可能是重述后的数值；首次披露日是估计值：91.5% 的记录被设为法定截止日，对逾期披露的公司（常是 ST 或经营困难的公司）存在前视。
- ST 状态是推断的；创业板和科创板的涨跌幅是 20%，这些板块的 ST 无法识别。

**19 个因子，9 类**：
- 规模；
- 价值：EP / BP / SP；
- 质量：ROE、毛利率；
- 成长：净利润同比、营收同比；

## 3. 选股模型

| 模型 | 说明 | IS RankIC / ICIR | OOS RankIC / ICIR |
|---|---|---|---|
| ICIR 加权 | 每月滚动选出的因子，按过去 24 个月已实现 IC 的均值 / 标准差加权 | 0.031 / 1.14 | 0.060 / 1.68 |
| **Ridge**（入选） | 每月用当月滚动选出的因子，把收益排名回归到这些因子上，L2 正则，每月重训 | 0.036 / **1.33** | 0.057 / 1.43 |
| GBDT | HistGradientBoosting，用全部 19 个因子，深度 4，叶子 ≥200，每季度重训 | 0.049 / 1.29 | 0.068 / 1.33 |

- **标签可用日期约束**：每个信号日的标签（从 t+1 日 VWAP 持有到下一次调仓的 t+1 日 VWAP）要到下一次调仓成交后才完全实现，记为 `label_date`。训练、IC 加权、样本内评估都只用 `label_date` 早于决策时点的样本，相当于 m 月只用 ≤ m−2 月的标签。有单元测试验证。
- **滚动选因子**：v3 之前，ICIR 加权和 Ridge 用的是"在整段样本内挑出来的因子和方向"，又在同一段时间比较 ICIR，相对用全部因子的 GBDT 有先天优势。v4 改为每月滚动筛选后，ICIR 加权的样本内 ICIR 从 1.44 降到 1.14，模型选择随之从 ICIR 加权变为 Ridge。
- **模型选择**：只看样本内 ICIR。Ridge 1.33、GBDT 1.29，差距不大，第 5.6 节把另外两个模型作为替代方案完整重跑（各自重新校准 λ）。
- **分组特征**：按中位数看，十分组大致单调，区分度主要集中在底部。**信号主要用来识别输家。**

## 4. 组合构建与回测

**风险模型（简化 Barra）**：
- 暴露：约 76 个证监会二级行业 + 6 个风格因子（规模、Beta、动量、波动、价值、流动性）。
- 每日做 √市值加权的 WLS 截面回归。
- 因子协方差用 EWMA（半衰期 90 天）；特异方差向截面中位数收缩 30%。
- 校准检查（λ = 5）：样本外事前跟踪误差平均 4.5%，事后 5.2%，事前略低估，量级一致。

**优化问题**：
```
max  αᵀw − λ·(w−b)ᵀ(XFXᵀ + D)(w−b) − 0.2%·‖w−w₀‖₁
s.t. Σw = 1, 0 ≤ w ≤ b + 3%（主动权重上限）, |行业偏离| ≤ 5%, |市值暴露| ≤ 0.2σ,
     单边换手 ≤ 40%/月, 不可买入股票的权重不能增加
α = 0.05 × σ_特异 × z（Grinold）;  λ：网格 {1, 2, 3, 5, 7, 10, 20, 50} 中样本内平均事前跟踪误差最接近 4% 的值 → λ = 5（平均持仓约 66 只）
w₀ = 回测中经过一个月涨跌、以及未成交之后的实际持仓（不是上个月的目标权重）
```

**回测假设**：
- t 日收盘出信号，t+1 日按 VWAP 成交。
- 一字涨停或停牌不能买；一字跌停或停牌不能卖。
- **账户记账**：持仓市值 + 现金 = 净值。卖出所得记入现金，买入和全部交易成本从现金支付；现金不够时所有买入等比例缩减，账户不借钱。买不进的资金留作现金（不摊给其他股票，避免把计划卖出的股票变成买入），现金不计利息，下次调仓重新投入。
- **四种仓位口径**分开记录：信号日实际持仓（优化器起点）→ 目标仓位 → 执行日交易前 → 成交后（含现金）。优化器约束的是计划换手（目标 vs 信号日实际持仓），成本和绩效用实际成交换手。
- 佣金万2.5 双边，滑点千1 双边；印花税只在卖出时收，2023-08-28 之前千1，之后万5。
- 非调仓日的权重随收益自然漂移。

### 4.1 实际持仓：最新一期示例（信号日 2026-10-30）

每个月的回测结果背后都是一份具体的股票清单，全部导出在 [holdings/](holdings/) 中：
- [latest_portfolio.md](holdings/latest_portfolio.md)：最新一期全部持仓、基准大权重股的处理、行业主动权重、相对上月的调仓；
- `optimized_monthly.csv`：组合优化每个月的完整持仓；
- `top50_equal_weight_monthly.csv`：Top50 等权对照组。

λ = 5 时，最新一期**目标仓位**（信号日 2026-10-30，数据截止时尚未执行）从 790 只可打分股票中持有 86 只，事前跟踪误差 4.4%，前 10 大合计 36%，计划单边换手 29.8%。
- **赚取超额的仓位**：排名靠前的股票被超配到上限（基准 + 3%），排名前 100 的股票里持有 41 只。
- **控制风险的仓位**：工商银行排名 494，却是权重最大的持仓（目标 6.54%，基准 3.87%）；贵州茅台排名 568，只持有 0.53%（基准 2.85%）。茅台等低分大票被大幅低配后，组合的市值暴露会偏小，优化器用大盘银行股把市值和行业暴露拉回基准附近。
- **上一期执行情况**（信号日 2026-09-30，执行日 2026-10-08）：计划换手 20.1%，实际成交 20.3%，没有受阻交易，成交后现金 0。

λ 的大小决定了组合是"集中押注"还是"贴着基准微调"：v1（λ = 2）持有 48 只；v2（λ = 50）持有 264 只。

- 2018–2021：−0.6%、−2.0%、−0.4%、−2.6%；
- 2022–2026：+1.8%、+5.8%、+4.3%、−5.4%、+0.5%。

**优化组合 vs 同信号的 Top50 等权**：换手约 690% → 214%，成本拖累 2.2% → 0.7%，跟踪误差 10.1% → 5.2%，样本外 IR 从 −0.05 提高到 0.24。

**执行情况**：样本外 58 次调仓的平均计划换手 16.8%、实际成交 17.0%；没有出现买入受阻，卖出受阻 2 只次，成交后现金几乎为 0（交易成本从现金支付后买入等比例缩减）。

**约束满足率**（按实际成交后的持仓逐月检查，见 results.md）：样本外 58 次调仓中，行业、单票上限和换手全部满足，市值暴露 1 个月略超（0.21σ）；样本内 46 次中各有 1 个月行业偏离（最大 5.7%）、市值暴露和换手（建仓月 50%）超限。

### 5.2 Brinson 行业归因（年化，算术）与对账

| | 配置 | 选股 | 交互 | 合计 |
|---|---|---|---|---|
| IS | +1.92% | −3.06% | +0.32% | −0.82% |
| OOS | −0.73% | **+3.87%** | −1.50% | +1.63% |

Brinson（含交互项，现金作为一个收益为 0 的"行业"）精确解释的是"调仓后权重买入持有一个月"相对"信号日基准权重买入持有"的超额。它和绩效表里超额的差距逐项对账（样本外，年化）：

| Brinson 合计 | 交易成本 | 调仓日执行时点差 | 基准口径差 | = 实际超额（算术） | 复利口径差 | = 几何超额 |
|---|---|---|---|---|---|---|
| +1.63% | −0.67% | −0.09% | +0.32% | +1.18% | +0.27% | +1.45% |

- **调仓日执行时点差**：调仓日旧组合只赚开盘到 VWAP、新组合只赚 VWAP 到收盘，而 Brinson 按旧权重算整天。
- **基准口径差**：实际基准每天按前一日流通市值重新加权，并跟随月中成分股变化；Brinson 的基准在一个月内按信号日权重买入持有。
- **来源**：在行业约束下，样本外以**选股效应为主**（+3.9%），但被行业配置和交互项（合计 −2.2%）抵消了一半以上。

### 5.3 风险因子归因（年化主动收益贡献）

| | 行业 | 规模 | Beta | 动量 | 波动 | 价值 | 流动性 | 交易成本 | 个股特异 | 合计 |
|---|---|---|---|---|---|---|---|---|---|---|
| IS | +1.08% | +0.14% | −0.56% | −0.69% | −0.97% | +0.05% | +0.84% | −0.57% | −0.85% | −1.53% |
| OOS | −1.03% | +0.06% | −0.92% | +0.63% | −0.58% | −0.09% | +0.90% | −0.69% | **+3.02%** | +1.29% |

- 按日精确对账：行业 + 6 个风格 + 交易成本 + 个股特异 = 主动收益。"个股特异"是风险模型解释不了的部分，包括个股特异收益、月内权重漂移（暴露按调仓日权重计算）和调仓日执行时点。
- 样本外个股特异收益 +3.0% 是正的，但被行业（−1.0%）、Beta 和波动（合计 −1.5%）以及交易成本（−0.7%）吃掉了大半。所以集中持仓时，**非意图的风格和行业暴露是主要拖累**。

### 5.4 为什么 IC 稳定，组合结果却对参数敏感？

1. **信号不对称**：按中位数看，十分组的区分度主要集中在底部，信号主要用来识别输家。
2. **long-only 约束**：减配一只股票最多只能减到基准权重。v1（λ = 2）的转移系数只有约 0.30，七成的信息被约束吃掉。
3. **λ 决定了组合形态**：λ 小时组合集中，风格和行业暴露大，成本也高；λ 大时组合贴近基准，暴露被压到很小，剩下的主要是个股选择。v3 时样本外 IR 随 λ 从 −0.08（λ = 3）一路升到 0.91（λ = 50）；v4 改为滚动选因子后，这个关系平缓得多：λ = 2、5、10、50 分别为 0.22、0.24、0.33、0.45。贴近基准仍略好，但不再是决定性因素。
### 5.5 复现稳健性：两次独立下载的对比（v1 时做的检验）

为了检验"别人照着 README 能否复现"，在一个全新的空目录里克隆仓库、新建环境，从下载数据开始完整运行一遍（下载日期比原始数据晚 3 天）。

**数据层面几乎一致**：
- 1,435 只股票的日线价格逐条完全相同；
- 东方财富季报约 37.7 万条中，只有 24 条的公告日期、15 条每股收益被数据源修订；
- 跨源交叉验证的结果相同（收益一致率 99.95%）。

**但结果层面有差异**：

| | 原始结果 | 新下载，原样运行 | 新下载，固定原来的 11 个因子 |
|---|---|---|---|
| 入选因子数 | 11 | 12（多了 np_yoy） | 11 |
| Ridge 样本外 ICIR | 1.49 | 1.50 | 1.51 |
| 样本内 超额 / IR | −0.44% / −0.07 | +0.85% / 0.15 | +0.46% / 0.08 |
| **样本外 超额 / IR** | **+1.73% / 0.28** | **+1.10% / 0.18** | **+1.70% / 0.27** |
| 样本外 超额 vs 官方全收益 | +4.70% | +4.06% | +4.68% |
| 月度持仓权重重合度 | — | 平均 86% | — |

**原因**：因子筛选规则是硬门槛（|t| ≥ 2）。净利润同比因子 np_yoy 的样本内 t 值从 1.94 变成 2.10，刚好越过门槛被选入。固定原来的 11 个因子后，样本外结果回到 +1.70% / 0.27，与原始结果基本一致。

**结论**：
1. **信号层面稳健**：样本外 ICIR 在三次运行里都约为 1.5。
2. **组合层面对边界决策敏感**：一个处在门槛边缘的因子，就能让样本外 IR 在 0.18–0.28 之间变动。样本内超额也在 −0.4% 到 +0.9% 之间摆动。
3. **统计显著性有限**：样本外约 4.8 年，IR 0.28 对应的 t 值约为 0.28 × √4.8 ≈ 0.6，远低于 2。所以样本外超额应理解为"方向为正，但不显著"。
4. **改进方向**：用连续权重代替硬门槛（例如按 t 值平滑加权），或对门槛附近的因子做敏感性分析；发布结果时附上数据下载日期。

本仓库中的数字以原始下载（2026-11-12）为准。复现时出现与上表类似的差异属于正常现象。

另外，这次复现还发现了一个遗漏：数据审计用的 192 只 baostock 交叉验证样本，原先是手动下载的，`run_all.sh` 并不会下载它，导致新环境中审计的交叉验证一项为空。现在这份股票清单已存入仓库（`src/mf/xval_codes.txt`），由第 1 步自动下载，缺失时会打印警告。

### 5.6 稳健性、数据敏感性与容量（v2 新增）

详见 [robustness.md](robustness.md) 和可视化报告第 8 节。除"切分"组外，样本外均为 2022-01 ~ 2026-10。

| 组别 | 方案 | 样本外超额 | 样本外 IR |
|---|---|---|---|
| — | **主方案**：Ridge，目标跟踪误差 4% → λ = 5 | **+1.45%** | **0.25** |
| 参数 | 目标跟踪误差 3% → λ = 10 / 5% → λ = 2 | +1.54% / +1.59% | 0.33 / 0.23 |
| 参数 | 按样本内 IR 选 λ（v2 规则）→ λ = 50 | +1.07% | 0.45 |
| 参数 | 模型换成 ICIR 加权 / GBDT（各自按同一规则校准，λ 都是 7） | +0.58% / −0.93% | 0.10 / −0.25 |
| 约束 | Beta 与波动 ≤ 0.2σ / 全部风格 ≤ 0.2σ / 行业 ±2% | +1.95% / +0.58% / +2.33% | 0.38 / 0.11 / 0.42 |
| 切分 | 样本内截至 2020-12（样本外 2021-01 起）/ 截至 2022-12（2023-01 起），模型选择和 λ 重做 | +0.73% / +1.51% | 0.11 / 0.27 |
| 数据 | 财报晚一个月可得 / 去掉全部财报因子 / 随机丢失 10% 财报值 | +0.98% / +0.74% / +1.46% | 0.16 / 0.12 / 0.25 |

- **整体**：除 GBDT 外，所有方案的样本外 IR 都在 0.10–0.45 之间，方向一致为正，但没有一个显著。
- **参数**：λ 的影响比 v3 小得多；模型的影响最大，GBDT 做成组合后为负，尽管它的样本外 RankIC 最高（0.068）。
- **约束**：限制 Beta 与波动、收紧行业偏离后 IR 略升；限制全部 6 个风格后下降，说明部分超额来自流动性等风格暴露。
- **数据**：去掉财报因子或让财报晚一个月可得，IR 降到 0.11–0.16，财报因子有一定贡献。
- **成本**：同一组交易，成本翻倍时样本外超额 +0.74%，三倍时 +0.05%。
- **Bootstrap**（循环块长 21 天，5000 次）：样本外主动收益 95% 区间 [−3.9%, +6.5%]，IR 区间 [−0.72, 1.26]，重抽样中主动收益 ≤ 0 的比例 31%（这是围绕样本均值重抽样的占比，用来直观衡量不确定性，严格说不是 p 值）。
- **容量**（平方根冲击模型，σ·√参与率，在千1滑点之外）：1 亿元时额外冲击约 0.7%/年，5 亿元时约 1.5%/年，基本吃掉全部超额。
- **基准与数据覆盖**：自定义基准与官方中证800全收益每年相差 −5.3% ~ +4.0%；成分股中缺数据（主要是后来退市）的比例从 2016 年的 6.9% 降到 2026 年的 0.4%。情景假设：若这些股票年化跑输 50%，早年基准约被高估 3.5%/年，2022 年后不超过 1%/年（这是假设情景，不是上限）。

### 5.7 v2 方法修订对结果的影响

完整对比见 [revision_log.md](revision_log.md)（v1 对比 v2，当时 λ 仍按样本内 IR 选）。样本外 IR 从 v1 的 0.28 变为 v2 的 0.91，按修订拆分：

| 步骤 | 样本外 IR |
|---|---|
| v1（旧 IR 口径：几何超额 / 跟踪误差） | 0.28 |
| ① 改为新 IR 口径（同一条收益曲线） | 0.25 |
| ② 修复时间泄漏：样本内去掉 2021-11、2021-12 两个信号日，重新筛因子、选模型、选 λ | 0.78 |
| ③ 修复组合状态：优化器以实际持仓为起点 | 0.91 |

②的变化很大，但泄漏本身只涉及两个月的标签。它的作用是让三个"差一点"的样本内选择翻转了：np_yoy 入选（t 从 1.94 到 2.12）、模型从 Ridge 换成 ICIR 加权（1.439 对 1.428）、λ 从 2 换成 50。所以 IR 的提高**不能**解读为"修了泄漏之后策略变好了"。

### 5.8 v3：按目标跟踪误差选 λ

（本节数字是 v3 的结果，当时仍用一次性选出的因子；v4 的结果见 5.9 节。）

v2 按"样本内 IR 最高"选 λ，但 {2, 10, 50} 三档在样本内的 IR 都是负数，λ = 50 被选中只是因为它亏得最少，这个选择几乎不含信息。v3 改为事先定好的**风险预算**：在网格 {1, 2, 3, 5, 7, 10, 20, 50} 中选样本内平均事前跟踪误差最接近 4% 的值，选择过程完全不看收益。

| 样本内校准 | λ = 1 | 2 | 3 | 5 | **7** | 10 | 20 | 50 |
|---|---|---|---|---|---|---|---|---|
| 事前跟踪误差 | 5.9% | 5.2% | 4.9% | 4.4% | **4.0%** | 3.6% | 2.6% | 1.5% |
| 样本内 IR（仅参考） | −0.38 | −0.47 | −0.49 | −0.46 | −0.46 | −0.43 | −0.45 | −0.29 |
| 平均持仓 | 36 | 42 | 46 | 55 | 65 | 83 | 132 | 244 |

| | v2（λ = 50，按样本内 IR） | v3（λ = 7，目标跟踪误差 4%） |
|---|---|---|
| 样本外超额 / IR | +2.01% / 0.91 | +1.03% / 0.20 |
| 跟踪误差 / 年化换手 | 2.2% / 164% | 4.7% / 269% |
| Bootstrap：主动收益 ≤ 0 的概率 | 4% | 35% |
| 平均持仓 | 约 270 只 | 约 77 只 |

**解读**：
1. 在一个事先定好、常见的 4% 风险预算下，这个信号做 long-only 增强的样本外超额约 +1%，统计上不显著。这是比 v2 更诚实的主结论。
2. v2 的 0.91 不是规则选出来的"好结果"，而是规则在样本内信息不足时，碰巧落在了样本外表现最好的一端。
3. 样本外 IR 随 λ 单调上升（λ = 3 → 50：−0.08 → 0.91）。如果事后据此把目标改成 1.5% 跟踪误差，就是用样本外数据调参，所以 v3 保留 4% 的目标不变。可以把"低跟踪误差下更好"作为一个需要新数据验证的假设。


### 5.9 v4：滚动选因子与回测修正

一次独立代码审查发现了以下问题，v4 全部修正：

1. **选因子的信息泄漏到模型比较**：ICIR 加权和 Ridge 用的是"整段样本内选出的因子和方向"，又在同一段时间比较 ICIR，对它们有利。→ 改为每月滚动选因子，只用当时已实现的标签。
2. **买入被阻断时把资金摊给其他股票**：可能把计划卖出的股票变成买入，甚至买入涨停股。→ 剩余资金留作现金；卖出被阻断时只按比例缩小买入。
3. **容量估算多乘了一次净值**：交易金额被高估约 20–33%。→ 改为按当时的资金规模计算。
4. **稳健性脚本修改了全局配置**：样本切分方案会改全局的样本内外分界且不恢复，后续方案可能用错分界（当时的结果碰巧未受影响）；缓存只看文件时间。→ 所有区间显式传参；缓存同时核对方案内容。
5. **换模型的对比沿用了别的模型的 λ**。→ 每个模型按同一规则各自校准 λ。
6. **措辞**："主动收益 ≤ 0 的概率"改为"重抽样中的比例"；缺失退市股的表格从"影响上限"改为"情景假设"；样本外已被多次查看，不再称"只评估一次"。

| | v3 | v4 |
|---|---|---|
| 选中的模型 / λ | ICIR 加权 / 7 | Ridge / 5 |
| ICIR 加权的样本内 ICIR | 1.44 | 1.14 |
| 样本外超额 / IR | +1.03% / 0.20 | +1.44% / 0.24（v5：+1.45% / 0.25） |
| 跟踪误差 / 年化换手 | 4.7% / 269% | 5.2% / 214% |
| 稳健性方案的样本外 IR 范围 | −0.25 ~ 0.91 | −0.25 ~ 0.45（除 GBDT 外 0.10 ~ 0.45） |

**解读**：主结论变化不大（超额 +1% 左右、不显著），但结果对 λ 的敏感度明显下降，各方案收敛到一个窄得多的区间。v3 时"越贴近基准越好"的强规律，有一部分来自一次性选因子带来的偏差。

**还没修的**：财报可用日期。东方财富的"最新公告日期"大多被后来的报告更新过，91.5% 的记录被设为法定截止日。对按时披露的公司这只是偏保守；但对真正逾期披露的公司（常是 ST 或经营困难的公司）等于提前使用，数值也可能是修订后的版本。彻底修复需要首次披露日历这类新数据源。

### 5.10 v5：账户记账、仓位口径与规则冻结

1. **账户记账**：回测从"权重向量"改为"持仓市值 + 现金"。卖出所得记入现金，买入和全部交易成本从现金支付，现金不足时所有买入等比例缩减，账户永不借钱；买不进的资金留作现金。
2. **四种仓位口径**：信号日实际持仓（优化器起点）、目标仓位、执行日交易前、成交后（含现金）分别记录。持仓 CSV 各占一列，每期另有一行现金；`status` 标出买入受阻、买入缩减、卖出受阻、待执行。换手分"计划"（优化器约束）和"实际成交"（成本和绩效）两个口径，HTML 页面两条线一起画。
3. **归因恒等式**：Brinson 把现金当作收益为 0 的"行业"，组合权重恒为 100%，配置 + 选股 + 交互 = 组合收益 − 基准收益严格成立；Brinson 到实际超额的对账逐期相加为零误差。
4. **极端情形测试**（tests/test_execution.py）：首次建仓、买入受阻、卖出受阻、剩余现金再投入、股票调出指数（可卖 / 停牌卖不掉）、优化器把被迫卖出计入换手、仓位不满 100%、Brinson 与对账恒等式、持仓表口径、前瞻登记只追加。共 25 个测试。
5. **结果**：样本外超额 +1.44% → +1.45%，IR 0.24 → 0.25，其他数字的变化都在 0.01 以内。说明 v4 的执行逻辑已基本正确，v5 主要是让口径明确、可审计。

**规则冻结与前瞻样本**：

- 2026-11-15 把模型（Ridge）、λ（5）、选因子规则、约束、成本、样本切分和核心代码的指纹写入 [forward/frozen_rules.json](forward/frozen_rules.json)，之后不再修改。之后即使数据更新导致样本内规则选出别的模型或 λ，也继续使用冻结值并给出警告。
- 开发中看过的最后一个数据日是 **2026-10-30**：在此之前的全部结果（包括 2022 年起的"样本外"）都只算**历史回测**。
- 每期目标仓位在第一次生成时登记到 [forward/registry.csv](forward/registry.csv)（只追加不修改，附哈希和权重文件）。第一期是 2026-10-30 信号日的目标仓位（86 只），它的收益完全落在冻结之后。
- 前瞻收益只有在"规则与冻结版本一致"且"交易的目标与登记一致"时才有效；报告和可视化页面把前瞻结果放在最前面单独展示，与历史回测分开。

## 6. 研究过程中发现并修正的问题

这一节是面试时最有价值的部分。

| # | 问题 | 怎么发现的 | 修正 | 影响 |
|---|---|---|---|---|
| 1 | 财报"最新公告日期"不是首次披露日 | 审计显示报告中位滞后 466 天，明显不合理 | 用 min(最新公告日, 法定截止日) | 基本面缺失率 27% → 0.3%，因子更及时 |
| 2 | ST 推断误报多 | 和 baostock 真实 ST 标记对照，精确率只有 35% | 在交叉验证集上网格搜索窗口、触板次数、阈值 | 精确率 35% → 82% |
| 3 | 基准用的是价格指数，组合收益却含分红 | 对比 sh.000906 和 H00906 的逐年收益 | 改用全收益指数 | 超额虚高约 2–3%/年 |
| 4 | 优化器基准（流通市值）≠ 官方指数（自由流通） | 用基准权重组合复制基准，再对比逐年差异 | 主口径改为复原基准，官方全收益作为副口径 | 去掉每年 3–5% 的基准构造噪声 |
| 5 | 单票绝对上限 3%，导致结构性低配茅台等大票 | 基准里 3% 以上的大票合计约占 8.5% | 改为主动权重上限 b + 3% | 去掉核心资产行情里的系统性拖累 |
| 6 | 风险模型缓存过期，还是 116 只股票试跑时的版本 | 检查文件时间戳和维度 | 缓存早于数据集时自动重算 | 事前跟踪误差与事后对齐（5.2% vs 6.0%） |
| 7 | 样本内用到了样本外才实现的标签 | 审查：2021-12-31 信号日的标签要到 2022-02 才实现，却进入了样本内的因子筛选和模型比较 | 引入 `label_date`，所有样本内决策只用标签已实现的样本 | 三个边缘选择翻转，见 5.7 节 |
| 8 | 优化器以为当前持仓就是上月目标 | 审查：实际持仓随行情漂移、部分股票卖不掉，换手约束对着过时的仓位计算 | 优化器嵌入回测，每月以实际持仓为起点；按实际成交后的持仓检查约束 | 年化换手 185% → 164%，样本外 IR +0.13 |
| 9 | 夏普没扣无风险利率；IR 用几何超额 | 审查：与教科书定义不一致 | 夏普 = (日均收益 − rf) 年化 / 波动；IR = 日均主动收益 × 252 / 跟踪误差 | v1 的 IR 0.28 → 0.25 |
| 10 | 分行业归因漏了交互项；归因没有和实际超额对账 | 审查：分行业表只加了配置和选股 | 补交互项；新增 Brinson → 实际超额的逐项对账，因子归因中拆出交易成本 | 差异全部可解释（成本、执行时点、基准口径、复利） |
| 11 | λ 按样本内 IR 选，但候选 λ 的样本内 IR 全为负 | 审查校准表：选中的只是"亏得最少"的那个 | 改为按目标事前跟踪误差（4%）选，不看收益 | 样本外 IR 0.91 → 0.20，见 5.8 节 |
| 12 | 一次性选出的因子用于样本内模型比较 | 独立代码审查 | 每月滚动选因子，只用已实现的标签 | ICIR 加权样本内 ICIR 1.44 → 1.14，模型改选 Ridge |
| 13 | 买入被阻断时资金被摊给其他股票，可能把卖出变成买入 | 独立代码审查 | 剩余资金留作现金；卖出被阻断时只缩小买入 | 回测更贴近实盘，有单元测试 |
| 14 | 容量估算多乘一次净值；稳健性脚本改全局配置、换模型沿用别人的 λ | 独立代码审查 | 按当时资金规模计算；显式传参、缓存核对方案；各模型各自校准 λ | 冲击成本估计下降约 20–30% |
| 15 | 仓位口径混用：持仓表是目标、换手是实际成交，现金没有显式记录 | 用户审查 | 账户记账（持仓市值 + 现金）；四种仓位分列；计划 / 实际换手分开 | 结果变化 ≤ 0.01，口径可审计 |

## 7. 结论与改进方向

**结论**：
- 低风险 / 低关注类因子在中证800 上的预测能力**跨样本稳定**，三种模型的样本外 RankIC 在 0.057–0.068。
- 在 long-only、自定义流通市值基准、4% 跟踪误差预算下，样本外超额 +1.4%、IR 0.24，重抽样中主动收益 ≤ 0 的比例约 31%，**统计上不显著**。
- v4 之后，各种合理方案（λ、约束、切分、数据）的样本外 IR 收敛在 0.10–0.45，方向一致为正；GBDT 是例外（−0.25）。
- 集中持仓时，非意图的行业和风格暴露以及交易成本吃掉了大部分个股选择收益；容量在 5 亿元左右就基本耗尽。
- 一句话：**信号是真的，但用 long-only 组合把它变现的效率很低**。
- 样本外区间在迭代中被多次查看，以上结论需要在冻结后的前瞻样本上检验；规则已于 2026-11-15 冻结，第一期目标仓位已登记。

**改进方向（按优先级）**：
1. **组合构建**：已改为按风险预算选 λ、滚动选因子。下一步是对多个模型等权集成（而不是挑一个"冠军"），并在新数据上做真正一次性的样本外检验。
2. **提高转移系数**：对"输家"单独建模；在优化器里对底部股票施加更强的负 alpha；或者在可融券时采用 130/30 结构。
3. **数据**：使用首次披露日历和首次披露的财报数值（当前 91.5% 的财报按法定截止日对齐，逾期披露的公司存在前视）、时点行业分类和官方指数历史权重，补齐退市股票。
4. **模型**：用平滑权重代替 |t| ≥ 2 的硬门槛，动态应对质量和成长类因子在样本外失效。
5. **成本与容量**：用真实成交数据校准冲击模型的系数，并在优化器里直接加入冲击成本项。
