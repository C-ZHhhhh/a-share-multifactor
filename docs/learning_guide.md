## 0. 全局视角：一个多因子研究在解决什么问题？

目标：在每个调仓日 t，给股票池里的每只股票一个**预期超额收益的打分**，再把打分变成一个**在风险约束下最优**的持仓，最后用**未来真实发生的数据**检验它是否赚钱、钱从哪里来。

```
数据 → 清洗/审计 → 因子 → 预处理 → 单因子检验 → 因子筛选/合成(模型) → 风险模型 → 组合优化 → 回测 → 样本外 → 归因
```

贯穿全程的三条纪律（面试必问）：
1. **无前视偏差 (look-ahead bias)**：t 时刻只能用 t 收盘前已知的信息。
2. **无幸存者偏差 (survivorship bias)**：股票池必须是"当时"的成分股，而不是今天的。
3. **样本内/样本外分离**：所有"选择"(因子、参数、模型) 只能在样本内做，样本外只评估一次。

## 1. 数据获取与质量审计（`data_fetch_ak.py`, `data_fetch.py`, `panel.py`, `data_audit.py`）

**做了什么**
- **下载的数据**：
  - 新浪：不复权日线和**后复权因子 f**；
  - 东方财富：2014Q1 起的季度业绩报表；
  - 中证：全收益指数；
  - baostock：每月的沪深300 + 中证500 成分股快照（构成**时点中证800 股票池**）、证监会行业、上市日期。
- **日收益**：preclose = close(t−1)·f(t−1)/f(t)，日收益 = close/preclose − 1。分红送转因此自动包含在内，也不需要前复权。
- **停牌**：没有成交的日子收盘价向前填充，收益记 0，并标记为不可交易。
- **ST**：新浪不提供 ST 标记，所以用涨跌停行为推断（±5% 涨跌停、没有大幅波动），推断参数用 baostock 的真实 ST 标记做网格搜索校准。
- **涨跌停**：按板块、ST 状态和日期计算涨跌停价（创业板 2020-08-24 起改为 20%），标记涨停、跌停和一字板。
- **时点基本面**（重点）：
  - 东方财富只给"最新公告日期"，它常常是次年重述比较数据的日期，不是首次披露日。所以首次披露日估计为 min(最新公告日, 法定截止日)：一季报 4/30、半年报 8/31、三季报 10/31、年报次年 4/30；
  - 公告**次日**起才可以使用；
  - TTM = 本期累计 + 上年年报 − 上年同期累计；
  - 每股指标乘以 f(公告日)/f(t)，换算到当天的股本口径，送转股不会让 EP 跳变。

**审计检查了什么**
- **数据完整性**：重复记录、非交易日、交易日缺口、OHLC 逻辑。
- **跨源交叉验证**：新浪 vs baostock，比较收盘价、日收益和 ST。
- **异常与缺失**：超过涨跌停的收益、停牌和 ST 比例、字段缺失率、报告滞后天数。
- **用成分股复原中证800**，再和官方**全收益**指数对比。

**两个重要的口径问题**
1. **价格指数 vs 全收益指数**：组合收益含分红，基准也必须含分红，否则超额每年虚高 2–3%。
2. **流通市值 vs 自由流通市值**：官方指数剔除了控股股东持股，我们只有流通市值，两者每年差 3–5%。所以主口径基准用复原的流通市值加权组合（也就是优化器实际跟踪的那个），官方指数作为副口径。

**面试问题**
- *前复权和后复权的区别？回测用哪个？* 前复权会随未来的分红改写历史价格；用后复权因子推导的收益率更安全。
- *怎么处理停牌？* 停牌日收益记 0，不参与因子统计；调仓日停牌的股票不能买卖。
- *什么是幸存者偏差？* 只用今天还存在的股票做回测，会排除掉后来退市或被调出的差股票，从而高估收益。本项目还有 79 只退市股缺数据，属于残余偏差。
- *财报怎么防前视？* 见上面"时点基本面"。

## 2. 因子构建与有效性检验 (`factors.py`, `dataset.py`, `factor_test.py`)

**19 个因子，9 大类**：规模、价值 (EP/BP/SP，来自时点财报)、质量 (ROE_TTM、毛利率)、成长 (净利润同比、营收同比)、动量 (12-1)、反转 (1M)、波动 (总波动、特质波动、Beta、MAX)、流动性 (换手、异常换手、Amihud)、量价 (价量相关、偏度)。

**截面预处理 (每个调仓日独立做)**
1. 缺失值 → 行业中位数填充
2. **MAD 去极值**：`median ± 5 × 1.4826 × MAD`，比 3σ 对极端值更稳健
3. Z-score 标准化
4. **行业 + 市值中性化**：对行业哑变量和 ln(市值) 回归，取残差。目的是让因子不只是"押注小盘"或"押注银行"的伪装

**标签**：t 日收盘出信号 → **t+1 日 VWAP 买入** → 持有到下个月末的 t+1 VWAP。比"t 日收盘买入"更贴近实盘。

**检验指标**
| 指标 | 含义 | 经验阈值 |
|---|---|---|
| RankIC | 因子值与下期收益的 Spearman 相关 | \|IC\| > 0.02~0.03 有意义 |
| ICIR | IC 均值 / IC 标准差 (×√12 年化) | > 0.5 较好 |
| t 值 | IC 均值显著性 | \|t\| > 2 |
| 分组单调性 | 五分组收益是否单调 | 越接近 1 越好 |
| IC 衰减 | 对未来 k 个月收益的 IC | 衰减慢的因子适合低频调仓 |
| 因子自相关 | 相邻两期因子排名的相关 | 越高，换手越低 |

**因子筛选**（只在样本内做）：|t| ≥ 2 且 |ICIR| ≥ 0.5，按 |ICIR| 排序做贪心选择，与已入选因子相关性 ≥ 0.6 的剔除。

**面试问题**
- *IC 和 RankIC 的区别？* RankIC 对极端值不敏感，A 股更常用。
- *为什么要中性化？* 避免因子收益被市值或行业 beta 主导。比如不做市值中性时，A 股很多因子本质上都是小盘因子。
- *IC 高但多空收益低可能是什么原因？* 收益集中在难以交易的尾部（涨停、小票），或者分组内部非线性。

## 3. 量化选股模型 (`models.py`)

三种模型，全部**滚动扩展窗口 (walk-forward)** 训练：
1. **ICIR 加权合成**：权重 = 过去 24 个月 IC 均值 / IC 标准差。这是业内的传统基线
2. **Ridge 回归**：截面上把因子回归到"收益排名"标签，L2 正则防止共线性
3. **GBDT** (HistGradientBoosting)：使用全部 19 个因子，可以捕捉非线性和交互。参数刻意保守（深度 4、叶子节点 ≥ 200 个样本）

**关键细节：1 个月的间隔 (GAP)**
t 月的标签（t+1 → 下月 t+1 的收益）要到**下个调仓日之后一天**才完全实现。所以在 m 月训练时只能用 ≤ m−2 月的标签。很多新手项目在这里有前视偏差。单元测试 `test_walk_forward_has_no_lookahead` 专门检查这一点。

**标签用收益排名而不是收益本身**：横截面排名对极端收益更稳健，而且我们只关心相对强弱。

**模型选择**：用样本内（2018–2021）的预测 ICIR 选出最终模型。样本外只看结果，不再调整。

## 4. 组合构建与回测 (`risk.py`, `optimizer.py`, `backtest.py`)

**风险模型（简化 Barra）**
- 暴露 X = 行业哑变量 + 6 个风格因子（规模、Beta、动量、波动、价值、流动性）
- 每日用 √市值 加权的 WLS 截面回归 `r = X f + u`，得到因子收益 f 和特异收益 u
- 协方差 Σ = X F Xᵀ + D，F 和 D 用 EWMA（半衰期 90 天）估计；特异方差向截面中位数收缩

**为什么不直接用样本协方差？** 800 只股票、250 天数据，样本协方差矩阵奇异且噪声巨大。结构化模型把参数从 N² 降到 K² + N。

**优化问题**
```
max  αᵀw − λ·(w−b)ᵀΣ(w−b) − c·‖w − w₀‖₁
s.t. Σw = 1, 0 ≤ w ≤ b + 3%, |行业偏离| ≤ 5%, |市值暴露| ≤ 0.2σ, 单边换手 ≤ 40%
```
- α 用 Grinold 公式：`α = IC × σ_specific × z-score`，把打分转成收益量纲
- λ 只用样本内校准（选 IR 最高的）
- 约束不可行时逐级放松，保证每期都有解
- 单票上限设在**主动权重**上（b + 3%），而不是绝对 3%：茅台在基准里最多占 6%，绝对上限会强制低配核心资产

**回测引擎的 A 股现实约束**
- t 日信号，t+1 日 VWAP 成交
- 一字涨停/停牌**不能买**，一字跌停/停牌**不能卖**（保留原仓位，其余按比例缩放）
- 佣金万2.5 双边、滑点千1 双边、印花税卖出单边（2023-08-28 从千1 降到万5）
- 非调仓日的权重随收益自然漂移

**面试问题**
- *Top-N 等权和优化组合的区别？* Top-N 简单、alpha 暴露高，但会有大量无意的行业和风格暴露；优化组合用风险约束换取更稳定的超额（更高的 IR、更小的回撤）。
- *换手约束为什么重要？* A 股成本高（单边约 0.15–0.2%），月度 100% 换手一年就要损失 2–4%。

## 5. 样本外验证与绩效归因 (`metrics.py`, `attribution.py`)

**绩效指标**：年化收益、波动、夏普、最大回撤、卡玛；相对基准的超额年化、跟踪误差、**信息比率 IR**（主动管理最重要的指标）、月度胜率、换手、成本拖累。

**两种归因**
1. **Brinson（行业）**：超额收益 = 配置效应（超配了涨得好的行业）+ 选股效应（行业内选对了股票）+ 交互效应。多因子组合做了行业中性约束，所以合理结果是**选股效应占主导**
2. **因子归因（风险模型）**：主动收益 = Σ 主动风格暴露 × 因子收益 + 特异收益。如果超额主要来自"市值"或"波动率"暴露，说明 alpha 只是风格 beta 的伪装

**样本外的意义**：IS 和 OOS 的差距就是过拟合程度。OOS 的 IC 或 IR 下降 30–50% 是正常的；如果 OOS 直接失效，要回头检查前视偏差和过拟合。

**转移系数（Transfer Coefficient）**：主动权重和 alpha 的截面相关系数。基本定律的完整形式是 IR ≈ TC × IC × √N。long-only、权重上限、换手等约束都会降低 TC。本项目 IC 稳定，但 TC 只有 0.30：信号主要识别输家，而多头组合最多只能把输家减配到 0。这是"IC 很好、组合一般"的典型原因。

## 6. 面试 / 简历的讲法（STAR）

- **S**：A 股中证800 股票池，月频调仓，目标是稳定跑赢基准
- **T**：搭建从数据到归因的完整研究框架，严格控制前视、幸存者和过拟合偏差
- **A**：时点数据 + 跨源审计 → 19 个因子检验 → 三种 walk-forward 模型 → Barra 式风险模型 + cvxpy 优化 → 含 A 股交易限制的日频回测 → Brinson 和因子归因
- **R**：用 `reports/results.md` 里的**真实样本外数字**（不要美化，面试官会追问）

常见追问准备：
1. 你的 alpha 来源是什么？（看因子归因表）
2. 样本外为什么衰减？（因子拥挤、风格切换，例如 2021 年后小盘/微盘行情、2024 年初微盘崩盘）
3. 如果资金规模放大 10 倍，什么会失效？（冲击成本、流动性因子容量）
4. 怎么进一步改进？（提高转移系数、约束 Beta 和波动暴露、行业时点分类、首次披露财报值、交易成本模型）
